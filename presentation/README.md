# حزمة العرض — بصائر

حزمة عرض تقديمي لمشروع بصائر الرقمي: عرض اشتراكي ثلاثي وثلاثون شريحة، وسكريبت التدريب، ودليل المعاينة، وأداة فحص السلامة.

---

## كيفية التشغيل

1. افتح `presentation/slides.html` مباشرة في المتصفح.
2. استخدم مفاتيح `n` أو `N` لإظهار/إخفاء ملاحظات المتحدث.
3. اضغط `g` أو `G` أو `i` أو `I` لعرض/إخفاء نظرة عامة على الشرائح.
4. اضغط `f` أو `F` للتبديل إلى وضع ملء الشاشة.

> لا حاجة لخادم محلي — العرض ثابت يعمل بالتصفح المباشر.

---

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `ArrowLeft` | الشريحة التالية (متوافق مع RTL) |
| `ArrowRight` | الشريحة السابقة (متوافق مع RTL) |
| `Space` / `PageDown` | الشريحة التالية |
| `PageUp` | الشريحة السابقة |
| `Home` | الشريحة الأولى |
| `End` | الشريحة الأخيرة |
| `f` / `F` | تبديل ملء الشاشة |
| `n` / `N` | تبديل ملاحظات المتحدث |
| `g` / `G` / `i` / `I` | تبديل نظرة عامة |
| `Escape` | إغلاق نظرة عامة |

> النقر باللمس (swipe) مدعوم أيضًا ومتوافق مع RTL.

## الملفات

| الملف | الوظيفة |
|---|---|
| `slides.html` | العرض التقديمي الرئيسي — 33 شريحة بالعربية |

| `qa-guide.md` | دليل الأسئلة والإجابات قبل العرض |
| `smoke-test.mjs` | أداة فحص سلامة بنية العرض |

---

## التحقق من سلامة العرض

```bash
node presentation/smoke-test.mjs --min 33
```

الفحص يتحقق من 13 شرطًا على بنية العرض. النتيجة المتوقعة: 33 شريحة، 13/13 فحوصات ناجحة.

---

## متطلبات بيئية

- **إنترنت:** مطلوب لتحميل خطوط Google Fonts المستخدمة في العرض.
- **jsdom:** مطلوب لتشغيل `smoke-test.mjs` (موجود في الاعتماديات التطويرية `devDependencies`).
- **عرض PWA/أوفلاين:** يتطلب بناء الإنتاج:`pnpm build && pnpm start` (Service Worker معطل في وضع التطوير).
